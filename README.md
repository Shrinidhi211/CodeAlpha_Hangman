# CodeAlpha Hangman Game

## Description

This project is a simple text-based Hangman game developed using Python.

The player has to guess a randomly selected word one letter at a time.

## Features

- Uses a predefined list of 5 words
- Randomly selects a word
- Allows the player to guess one letter at a time
- Allows a maximum of 6 incorrect guesses
- Displays the current progress of the word
- Console-based interface

## Technologies Used

- Python
- random module
- while loop
- if-else statements
- strings
- lists
- sets

## How to Run

1. Install Python.
2. Clone or download this repository.
3. Open the project folder in VS Code.
4. Run:

```bash
python hangman.py
